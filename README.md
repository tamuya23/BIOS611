Hi, this is my 611 Data Science Project. More to come.

This directory contains the shell/Docker orientation assignment:

* `answers.md` — written answers for Problems 1–9.
* `experiment.sh` — the positional-parameter experiment from Problem 3.
* `compare_man_pages.sh` — the sorted manual-page line-count script from Problem 9.
* `Dockerfile` — the Problem 8 image definition.

The Dockerfile is only needed for the Docker-specific part of the assignment.
The Bash scripts can be inspected with `bash -n` and executed directly with
Bash; `compare_man_pages.sh` should be run in the Docker image (or another
Linux system with the relevant manual pages installed).
